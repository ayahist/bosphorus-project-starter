# The Bosphorus Has Changed

An interactive scrollytelling project exploring how vessel traffic through the Bosphorus has evolved between 2006 and 2025.

Although fewer ships now pass through the strait, Turkish government data show that total gross tonnage and average vessel size have increased substantially, reflecting a shift toward fewer but much larger vessels.

The project combines narrative text, custom illustrations, animated charts and interactive mapping to explain how traffic through one of the world's most strategic waterways has changed over the past two decades.

## Data

- Turkish Ministry of Transport and Infrastructure
- Annual Bosphorus transit statistics (2006–2025)
- Vessel type statistics by year

Average vessel size was calculated by dividing annual gross tonnage by the number of vessels transiting the Bosphorus.
